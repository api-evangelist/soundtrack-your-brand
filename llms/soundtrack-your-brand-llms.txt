# Soundtrack Your Brand

> Soundtrack (Soundtrack Your Brand) is a business music streaming service. The Soundtrack API is a
> single-endpoint GraphQL API for building display, control and monitoring apps on top of Soundtrack —
> reading what is playing, controlling playback in a store's sound zones, pairing devices, and managing
> schedules and playlists. It is free for paying Soundtrack customers. This llms.txt was generated by the
> API Evangelist enrichment pipeline from the live GraphQL introspection and public docs (2026-07-21).

## API
- [Soundtrack GraphQL endpoint](https://api.soundtrackyourbrand.com/v2): single POST endpoint (queries + mutations); websocket for subscriptions
- [API documentation](https://api.soundtrackyourbrand.com/v2/docs): basics, queries, mutations, subscriptions, errors, rate limit
